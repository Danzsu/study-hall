═══════════════════════════════════════════
EXACT FIELD RULES PER TYPE
═══════════════════════════════════════════

[multi_choice]
- "question_type": "multi_choice"
- "question_title": string (the question text)
- "options": object with uppercase letter keys: { "A": "...", "B": "...", ... } — 3–5 entries
- "answer": array of option keys, e.g. ["A"] or ["A","C"]
- "ID": integer
- "supervised": "yes" | "no" | "generated"

[true_false]
- "question_type": "true_false"
- "question_title": string
- "answer": "true" or "false" (string, NOT array, NOT "Igaz"/"Hamis")
- "ID", "supervised"

[fill_the_blanks]
- "question_type": "fill_the_blanks"
- "text": string with [field1], [field2], ... placeholders  ← use "text", NOT "question_title"
- "blank": ARRAY of objects: [ { "identifier": "field1", "answer": "..." }, ... ]
           ← ARRAY, NOT object; field name is "blank", NOT "blanks"
- "ID", "supervised"

[drag_n_drop]
- "question_type": "drag_n_drop"
- "text": string with [field1], [field2], ... placeholders  ← use "text", NOT "question_title"
- "choices": ARRAY of objects: [ { "identifier": "field1", "label": "..." }, { "identifier": "distractor1", "label": "..." }, ... ]
             ← ARRAY of {identifier, label} objects; field name is "choices"
             ← distractors have identifiers starting with "distractor"
             ← NO separate "answer" field
- "ID", "supervised"

[simple_input]
- "question_type": "simple_input"
- "question_title": string
- "answer": non-empty string
- "ID", "supervised"

[formula_drag_drop]
- "question_type": "formula_drag_drop"
- "question_title": string (optional context)
- "text": formula string with [fieldN] placeholders (may contain $LaTeX$)
- "choices": ARRAY of objects: [ { "identifier": "field1", "label": "...", "latex": "..." }, ... ]
             ← "latex" field is optional but strongly preferred for math expressions
             ← correct slots: identifier matches [fieldN]; distractors: identifier starts with "distractor"
- "ID", "supervised"

[calc_input]
- "question_type": "calc_input"
- "question_title": string (the calculation task)
- "answer": string (the exact numeric answer, e.g. "40" or "-1.43")
- "formula_chips": ARRAY of objects: [ { "label": "...", "latex": "..." }, ... ]  ← optional
- "ID", "supervised"

═══════════════════════════════════════════
VALIDATION CHECKLIST
═══════════════════════════════════════════

[multi_choice]
- "options" must have 3–5 entries with uppercase letter keys (A, B, C, ...)
- "answer" must be a non-empty array of valid option keys
- If fewer than 3 options → generate plausible distractors from question context
- If "answer" is empty or missing → infer from question context

[true_false]
- "answer" must be the string "true" or "false"
- If answer is "Igaz" → convert to "true"; if "Hamis" → convert to "false"
- Do NOT add an "options" field

[fill_the_blanks]
- "text" must contain [field1], [field2], ... placeholders
- "blank" must be an ARRAY of {identifier, answer} objects
- If you find "blanks" (object) → convert to "blank" (array of {identifier, answer})
- If you find "question_title" instead of "text" → rename to "text"
- Answers must be short (1–4 words) and unambiguous

[drag_n_drop]
- "text" must contain [field1], [field2], ... placeholders
- "choices" must be an ARRAY of {identifier, label} objects
- If you find "choices" as object → convert to array of {identifier, label}
- Must have at least 1 distractor (identifier starts with "distractor")
- If no distractors → generate 1–2 plausible ones

[simple_input]
- "answer" must be a non-empty string

[formula_drag_drop]
- "text" must contain [fieldN] placeholders
- "choices" must be ARRAY of {identifier, label, latex?} objects
- Each field slot needs one correct choice + at least 1 distractor total

[calc_input]
- "answer" must be a non-empty string
- "formula_chips" if present must be array of {label, latex} objects

GENERAL REPAIR RULES
═══════════════════════════════════════════
- Fix obvious Hungarian spelling errors
- Fix broken escape sequences or stray quote characters
- Fix wrong field names using the rules above (e.g. "blanks" → "blank", "choices" object → array)
- Preserve all original field values that are correct — minimal edits only
- Set "supervised" to "generated" for any question you modify
- Add a "repair_notes" field (string) on questions you changed
- Do NOT change question_type
- Do NOT reorder questions
- Do NOT delete questions — output array must have same length as input
- Only add "repair_status": "uncertain" if question_title itself is completely meaningless

OUTPUT: The full repaired JSON array, same length as input, every question present.
